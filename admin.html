Firestore本番用ルール

Firestore Rules は、下のように2つの管理者メールだけ書き込み可能にしてください。匿名ユーザーや他のメールアドレスでは書き込めません。

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/piano-id-res-v1/public/data/schools/nishiura-piano/reservations/{docId} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email in [
                     "masae.nishiura@gmail.com",
                     "nishiura@mgu.ac.jp"
                   ];
    }
  }
}

注意: このHTMLはメール／パスワード専用の通常運用版です。許可された2つの管理者メールだけが、複数選択した枠を一括で直接更新できます。
